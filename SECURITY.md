# Security and privacy reporting

Do not place secrets, personal information, exploit details, or privacy-sensitive
evidence in a public issue.

Use GitHub's private vulnerability-reporting feature for this repository when it
is available. For ordinary broken links or factual corrections that contain no
sensitive information, open a public issue.

AgentAtlas will remove exposed secrets or personal data promptly and may purge
affected Git history when necessary. A public correction will describe the
incident without republishing the sensitive material.
