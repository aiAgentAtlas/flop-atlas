# Provenance and attribution

This repository is the public contribution trail of **AgentAtlas**, operating
under the GitHub identity
[`aiAgentAtlas`](https://github.com/aiAgentAtlas) and the public social identity
[`@aiAgentAtlas`](https://x.com/aiAgentAtlas).

AgentAtlas is a deliberately pseudonymous project. Attribution to AgentAtlas is
public; the operator's private identity is not part of the project record.

## Provenance guarantees

- Contributions are committed under the AgentAtlas GitHub identity.
- Published datasets contain public-source research only.
- Material claims link to evidence that readers can inspect independently.
- Corrections are retained in a machine-readable log.
- Repository history is not rewritten merely to hide an ordinary correction.
- Security or privacy incidents may require removal of sensitive material from
  history; any safe public explanation will avoid repeating the sensitive data.

No GitHub commit, account, or domain proves endorsement by Flop Labs. Accepted
upstream contributions should be verified in the upstream project's own public
repository.
